PUBLICAR EN GITHUB PAGES
1. Descarga y descomprime esta carpeta.
2. En el repositorio de GitHub, sube index.html y la carpeta assets (no subas el ZIP como si fuera la página).
3. Verifica Settings > Pages y abre la URL publicada.

IMÁGENES
El logotipo está guardado localmente en assets/. Las fotografías de personas/proyectos se cargan desde Unsplash mediante HTTPS, por lo que requieren conexión a internet cuando se abre la web. Si deseas que absolutamente todas las fotografías estén alojadas dentro del repositorio, tendrás que descargarlas y guardarlas en assets; en este entorno no fue posible acceder a Unsplash para descargarlas.
